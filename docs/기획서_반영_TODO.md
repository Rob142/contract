# 기획서 반영 TODO (기능 2·3·4)

작성일 2026-11-14 · 버전 0.1 (초안)

`AI 혁명 기획 내용 정리` 문서의 **기능 2 진행 현황 공유, 기능 3 증빙 및 정산, 기능 4 포트폴리오** 중 아직 없는 것을 모았다. 기능 1(계약 도움: 체크리스트·양식 채우기·클라이언트 동의 반복)과 매칭은 이번 범위에서 뺀다. 기존 구현은 [`전체_구현_TODO.md`](전체_구현_TODO.md)를 기준으로 한다.

- **ID 규칙:** `영역-번호`. `PG`=진행 공유(기능 2), `ST`=증빙·정산(기능 3), `PF`=포트폴리오(기능 4), `XC`=공통·보안·테스트.
- **우선순위:** 필수 = 기획서 핵심. 선택 = 문서에서 "부가적으로"라고 한 것이나 시간이 부족하면 미룬다.
- **의존 순서:** `XC`(첨부) → `PG`(공유 링크 → 클라이언트 뷰 → 피드백 → 수정 카운터) → `ST` → `PF`. 포트폴리오는 완료 프로젝트의 결과물·피드백을 가져오므로 `PG`가 끝나야 한다.

- [x] `XC-02` 첨부 API: `POST·GET·DELETE`(업로드, 목록, 삭제). 업로드는 기존 파일 검증(매직 바이트·크기)을 재사용하고, 허용 형식은 PDF·이미지·압축·영상으로 넓힌다
- [x] `XC-03` `GET /files/{id}` 다운로드: 소유권 확인 후 스트리밍, `Cache-Control: no-store`. 클라이언트 공유용은 `PG` 쪽 토큰 검사 경로를 따로 둔다
- [x] `XC-04` 외부 결과물 링크 검증: `http(s)`만 허용, 길이 제한, 표시할 때 `rel="noopener noreferrer"`
- [ ] `XC-05` 파일 용량 한도: 사용자별 총량과 파일당 크기(파일당 크기 제한은 기존 `max_upload_mb`로 적용됨, 사용자별 총량은 남음). 초과 시 413과 안내 문구
- [ ] `XC-06` 알림 기반(선택): `notifications` 테이블(받는 사람, 종류, 대상, 읽음 시각)과 목록·읽음 API. 이번 범위는 앱 안 알림(대시보드·알림 목록)만이다. 이메일·푸시는 만들지 않는다
- [x] `XC-07` 공개 API용 속도 제한: 토큰 없는 요청에 IP·토큰 단위 rate limit(기존 `BE-12` 확장)
- [x] `XC-08` 감사 기록 대상 추가: 공유 링크 생성·폐기, 단계 확인, 피드백, 수정 요청, 포트폴리오 공개 범위 변경

## ST. 기능 3: 증빙 및 정산

이미 있는 것: 인보이스 발행·취소·재발행, 입금 체크·취소, 입금 예정일, 연체 표시, PDF, 영수 문서. 아래는 비어 있는 부분이다.

- [x] `ST-01` `evidence_documents`(또는 `XC-01` 첨부의 종류 `evidence`) 설계 확정: 종류(세금계산서·현금영수증·계약서 사본·영수증·기타), 발행일, 금액(선택), 메모, 연결 대상(프로젝트, 인보이스 선택)
- [x] `ST-02` 증빙 업로드·목록·수정·삭제 API: 프로젝트 필터, 종류 필터, 월 필터
- [x] `ST-03` 프로젝트 상세 "서류" 탭: 그 프로젝트의 인보이스, 입금 확인 문서, 증빙을 한곳에 모아서 보여 준다(기획서 화면표의 서류 탭)
- [x] `ST-04` 서류·정산 화면 개편: 인보이스 목록(발행·입금 대기·완료)과 증빙 업로드를 같은 화면에 둔다. 기존 인보이스 화면과의 관계를 정한다(통합할지 탭으로 나눌지)
- [x] `ST-05` 월별 수입 합계 API: `GET /dashboard/monthly-income?from=&to=`. **입금일 기준 입금액(= 수입)**을 주 지표로 하고, **발행월 기준 청구액**은 참고로 구분해서 반환하고, 취소된 입금·초안 인보이스는 제외한다. 금액은 십진 문자열
- [x] `ST-06` 월별 합계 기준을 문서에 명시: "수입"은 입금일 기준이라는 점(확정), 세금·원천징수 반영 여부, 월 경계 시간대(KST)
- [x] `ST-07` 대시보드: 이번 달 수입 합계 카드 추가(지금은 이번 달 청구액만 있음). 청구액과 입금액을 나란히 보여 준다
- [x] `ST-08` 서류·정산 화면: 월별 합계 표·막대 그래프, 월 이동, 프로젝트별 내역으로 펼치기
- [x] `ST-09` 미수금 경고 강화: 입금 예정일이 지난 인보이스를 대시보드 상단 경고로 표시한다. 연체 일수와 클라이언트명, 바로 가기 버튼 포함
- [ ] `ST-10` 미수금 알림(선택): 입금 예정일 D-3·당일·초과 시 `XC-06` 알림 생성. 같은 인보이스에 중복 알림이 쌓이지 않게 한다
- [x] `ST-11` 클라이언트 공유 페이지에 인보이스 표시: 발행된 인보이스 목록·금액·입금 예정일·PDF. 초안은 제외하고, 입금 여부는 프리랜서 설정에 따라 숨길 수 있게 한다
- [x] `ST-12` 증빙 파일 보관 정책: 삭제 시 확인 절차, 인보이스·입금 이력과 연결된 증빙은 삭제 제한
- [x] `ST-13` 증빙·월별 합계 테스트: 취소된 입금 제외, 월 경계(말일 23:59·1일 00:00), 초안 제외, 소유자 격리
- [x] `ST-14` 안내 문구: 세금계산서·현금영수증은 국세청 시스템에서 발행하고, 서비스는 업로드·정리만 한다는 설명을 화면에 둔다

## PF. 기능 4: 포트폴리오

### PF-A. 데이터·API

- [x] `PF-01` `portfolio_items` 테이블: owner_id, project_id(유일), 제목, 설명, 직군, 작업 기간(시작·종료), 대표 이미지(file_id, nullable), 상태(초안·공개 준비·보관), 공개 범위(비공개·링크 공유·전체 공개)
- [x] `PF-02` `portfolio_assets` 테이블: item_id, 원본 attachment_id, 노출 여부, 순서. 진행 중 올린 결과물 중 **프리랜서가 고른 것만** 쓴다
- [x] `PF-03` `portfolio_feedback_quotes` 테이블: item_id, 원본 feedback_id, 인용문, 표시 여부, 이름 표기 방식(익명이 기본, 실명은 선택), 공개 동의 확인 여부·시각(`PF-14`). 클라이언트 피드백을 그대로 쓰되 노출은 선택
- [x] `PF-04` 카드 초안 생성 `POST /projects/{id}/portfolio-draft`: 완료된 프로젝트에서 결과물, 작업 기간, 직군, 피드백을 모아 초안을 만든다. **저장하지 않고 반환**한 뒤 확정할 때 저장(프로젝트 초안과 같은 방식)
- [x] `PF-05` 포트폴리오 CRUD: 목록(상태·직군 필터), 상세, 수정, 삭제. 프로젝트가 완료 상태가 아니면 초안 생성에 경고만 하고 막지는 않는다
- [x] `PF-06` 공개 범위 변경 API: 변경 시 감사 기록. 전체 공개는 공개 링크(slug) 생성이 필요하다
- [x] `PF-07` 공개 조회 API: 링크 공유·전체 공개 항목만 반환. 공개 응답 스키마는 허용 목록 방식으로 만든다

### PF-B. 프론트

- [x] `PF-08` 포트폴리오 목록 화면(카드 그리드): 직군·상태 필터, 공개 범위 배지, 빈 상태에서 "완료한 프로젝트로 카드 만들기"
- [x] `PF-09` 카드 초안 편집 화면: 제목·설명 편집, 결과물 선택·순서 변경, 피드백 인용 선택, 대표 이미지 지정, 미리보기
- [x] `PF-10` 공개 범위 선택 UI: 비공개·링크 공유·전체 공개 설명, 변경 전 확인 문구, 링크 복사
- [x] `PF-11` 공개 포트폴리오 페이지(로그인 없음): 카드 상세와 프리랜서 소개. 프로젝트 상세의 "포트폴리오로 만들기" 버튼 연결
- [ ] `PF-12` 사이드바 메뉴에 "포트폴리오" 추가(완료), 남은 일: 완료 처리 시 "포트폴리오 카드를 만들까요?" 제안

### PF-C. 기밀·동의

- [x] `PF-13` 기밀 표시 규칙: 클라이언트명·금액·계약 조건은 **기본적으로 공개에서 제외**한다. 클라이언트명 노출은 프리랜서가 명시적으로 켠 경우만 허용하고, 켤 때 "클라이언트 동의를 받았는지" 확인 문구를 띄운다
- [x] `PF-14` 클라이언트 피드백 노출 동의: 피드백 인용을 공개·링크 공유 범위에 쓰려면 프리랜서가 "클라이언트에게 공개 동의를 받았다"를 체크해야 한다. 체크 시각과 확인자를 감사 기록에 남기고, 체크 전에는 인용이 비공개 범위에서만 보인다. 이름 표기는 익명이 기본

## 확정된 결정 (2026-11-14)

| # | 결정 | 반영 항목 |
| --- | --- | --- |
| 1 | 공유 페이지에는 계약의 **핵심 조건(금액·기간·포함 수정 횟수)만 읽기 전용**으로 표시한다. 계약서 원문·PDF는 보여 주지 않는다. 동의 버튼은 기능 1이라 제외 | `PG-15`, `PG-18` |
| 2 | 월별 수입은 **입금일 기준 입금액**이다. 청구액(발행월 기준)은 따로 나란히 보여 준다 | `ST-05`~`ST-08` |

| 4 | 공유 링크는 **만료 없음, 프리랜서가 수동 폐기·재발급**한다. 만료일 컬럼은 두되 기본값은 비운다 | `PG-10`, `PG-12` |
| 5 | 피드백을 공개 포트폴리오에 쓰려면 **프리랜서가 동의받았음을 확인**해야 하고, 이름은 **기본 익명**으로 표시한다 | `PF-03`, `PF-13`, `PF-14` |
